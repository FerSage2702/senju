МИНИ-САЙТ КЛАНА СЕНДЖУ

Файлы:
- index.html — главная
- rules.html — правила
- ranks.html — система рангов
- lore.html — лор и картинки

Для Google Sites:
1. Разместите каждый HTML на отдельном публичном хостинге/сервисе, который отдаёт HTML как страницу.
2. В Google Sites создайте отдельные страницы: Главная, Правила, Ранги, Лор.
3. В каждой странице используйте «Вставить → Встроить → По URL» и укажите URL соответствующего HTML.
4. Все страницы уже связаны между собой меню.

Важно: Google Sites не исполняет произвольный HTML прямо в редакторе страницы. Обычно нужен внешний URL для каждого HTML.
